# Icons

23 line icons from the app's sprite (`hyperocr/static/index.html`), on a 24px grid: stroke 1.8, round caps and joins, no fill. As files they are drawn in black (`#000000`, the light `label`); in the app they are inlined from the sprite and take `currentColor`, so recolour them by inlining, not with `<img>`.

- `scan.svg`: the drop zone (pick files).
- `doc.svg`: a PDF file; the searchable PDF row; the scan placeholder.
- `photo.svg`: a picture file whose preview can't be shown (HEIC).
- `plus.svg`: Add More Files.
- `x.svg`: remove a file.
- `handle.svg`: drag to reorder.
- `chev.svg`: disclosure; flips in right-to-left.
- `updown.svg`: a picker row's value.
- `check.svg`: success, checked rows, finished steps.
- `warn.svg`: warnings and errors.
- `info.svg`: About; info notices.
- `globe.svg`: language button; Languages row.
- `appearance.svg`, `sun.svg`, `moon.svg`: theme button in Automatic, Light and Dark (`appearance` has one filled half-disc).
- `cpu.svg`: the OCR engine.
- `viewfinder.svg`: resolution.
- `table.svg`: tables.
- `text.svg`: Markdown; the headers-and-footers option.
- `down.svg`: download.
- `refresh.svg`: Software Update.
- `lock.svg`: the privacy footer.
- `stack.svg`: one document among several.
